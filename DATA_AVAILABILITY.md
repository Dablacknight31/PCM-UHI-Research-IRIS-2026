## Acquiring inputs for a future run

1. Read [methodology](docs/methodology.md) for exact asset IDs, date windows, QA/scaling, grid, sampling and time alignment. Preserve the original dataset versions/epochs.
2. Obtain authorized Earth Engine access and use your own project through `PCM_UHI_EE_PROJECT`; credentials are not bundled. The cleaned preliminary functions acquire the documented collections in a deliberate fresh run.
3. Obtain the exact permission-cleared researcher workbook; verify its SHA-256 before placing it at the path in [input locations](configs/input_locations.json). A recreated workbook from selected values would not reproduce the original four-sheet artifact or satisfy its identity seal.
4. Resolve FAO boundary distribution terms independently. Any replacement boundary or updated source product creates a new input lineage and may change the selected hotspot; do not silently call it the historical baseline.
5. Use a new `PCM_UHI_OUTPUT_ROOT`. Full remote acquisition/annual orchestration was not tested here. [Reproducibility](REPRODUCIBILITY.md) records that limit.

The public package is an inspectable code-and-saved-results package with explicit acquisition gaps. Exact reproduction of all preprocessing and figures from a bare public clone is not claimed. No project-wide license is selected; source data terms do not automatically grant reuse rights for all repository contents.
