# Scientific release scope

The public package contains final scientific code and supporting scripts, permitted inputs, saved numerical results, original research figures, model configurations, methodology, reproducibility instructions and required third-party attribution.

The intact PCM and collated source workbooks are not distributed because compilation/source permissions are unresolved. GAUL boundary geometry and inseparable masks, rasters and city-map derivatives are not distributed. No final manuscript is included. [Data availability](../DATA_AVAILABILITY.md) records access and permissions.

The package includes the author-generated selected hotspot geometry, weather forcing, permitted roof-footprint inputs, all three annual PCM/L=0 pairs, accepted annual atmospheric statistics and compact fields, partial feasibility outputs, and saved derived comparisons. All 34 included PNGs are preserved original images. Seven exact generators and two exploratory numerical exports remain unavailable.

Only repository-relative scientific references are included. Dependencies without public files are described as retained privately. Source datasets, equations, parameters, run identities and scientific input/output relationships remain documented. [Scientific provenance](scientific_provenance.md) explains the identity and checksum policy.

The package does not establish independent full annual reproduction, exact regeneration of all manuscript figures, field validation, citywide cooling, or deployment readiness. No project-wide open-source license has been selected; third-party notices apply to their respective data.
